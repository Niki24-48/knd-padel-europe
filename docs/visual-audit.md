## Alertas de procedencia y terceros

- Una imagen visualmente adecuada no debe presentarse como proyecto KND si su autoría y ubicación no están confirmadas.
- Las imágenes de competidores o proveedores con marca visible no deben reutilizarse, retocarse ni eliminarse de su contexto para aparentar propiedad.
- La ausencia de marca de agua no demuestra que exista licencia de uso.
- Los renders OP-01, OP-02, OP-03, OP-06 y OP-07 se han asociado por su nomenclatura local, pero siguen siendo provisionales hasta contrastarlos con planos. OP-04 y OP-05 todavía usan fichas del brandbook como placeholders explícitos.
- Las muestras de césped validan color y apariencia general, no especificaciones ni pertenencia a OP X10, R9, S12, S9 o S7.
- Las páginas de proyecto deben usar un placeholder editorial claramente rotulado antes que reutilizar una pista genérica como si fuera la instalación real.

## Material visual que falta

1. Para cada pista OP-01 a OP-07: fotografía general, lateral, trasera, acceso, cristales, malla, anclajes e iluminación; incluir el nombre de archivo y el modelo confirmado.
2. Para cada proyecto publicado: fotografías reales, nombre del proyecto, ubicación, año, número de pistas, modelos instalados y permiso de publicación.
3. Para fabricación: corte, soldadura, tratamiento superficial, control de calidad, vidrio, embalaje y expedición.
4. Para OP X10, R9, S12, S9 y S7: macro de fibra, vista instalada, color, relleno y ficha técnica asociada al sistema correcto.
5. Para cada cubierta: vista exterior, interior, unión estructural, drenaje y una referencia de escala; para la retráctil, secuencia abierta y cerrada.
6. Para home y banners: fotografía panorámica propia en alta resolución, con encuadre horizontal y espacio seguro para titulares.

## Recomendación operativa

Mantener `src/data/imageManifest.js` como fuente única de verdad. Cualquier imagen nueva debe entrar con procedencia, asociación de producto, estado, textos alternativos ES/EN y usos permitidos antes de incorporarse a una página pública.
